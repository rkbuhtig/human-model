# 권위가 없다는 것은 흔적이 없다는 뜻이 아니다

> 날짜: 2026-08-07  
> 지위: 비권위 연구 일기  
> 관련 배치: `research/terminology/projects/chapter-11/`

Chapter 11을 조사하기 전에는 질문이 비교적 단순해 보였다.

```text
ρ_fast와 𝔄 사이의 빈자리를
ΦΩ가 채우는가.
```

Chapter 09은 순간적인 가역 후보 상태와 권위 원장 사이에 지속 가능하지만 비권위적인 내부 변화가 필요하다는 공백을 남겼다. Chapter 10은 꿈·수면·재주소가 다음 상태를 바꿀 수 있어도 그 변화가 어디에 남는지 정의하지 못했다.

그래서 `NEWQUAL22`의 `medium metric`, `impedance layer`, `shaping`이라는 이름을 보면 답이 나왔다고 생각하기 쉽다.

```text
ΦΩ
= 경험이 남는 매질
```

실제 추출을 시작하자 이 등식은 유지되지 않았다.

## 직접 정의는 매질보다 routing potential에 가까웠다

원문의 가장 강한 수식은 이것이다.

```text
candidate availability
× effective accessibility
→ call probability
```

`K_open`이 열려 있는 후보를 제공하고, `E_{ΦΩ}`가 후보별 접근 비용을 주며, 둘이 `P_call`을 기울인다.

이 구조는 중요한 수확이다.

```text
느낌·정서·친숙함·회피·끌림은
사실을 증명하지 않으면서도
무엇이 먼저 떠오르고 호출되는지를 바꿀 수 있다.
```

이전 장의 `Influence ≠ Warrant`가 금지 규칙에 가까웠다면, 이번 장은 처음으로 선택 분포 수준의 적극적 형식을 준다.

하지만 그 식이 직접 제공하는 것은 현재 후보의 차등 접근성이다.

```text
E_{ΦΩ}(v|ctx)
≈ RoutingPotential
```

이지:

```text
persistent medium
plastic state
experience itself
```

가 아니다.

`medium`, `metric`, `impedance`, `energy`라는 네 이름은 같은 문장에 있지만 각 이름이 요구하는 구조가 다르다.

```text
medium
→ 지속 가능한 state와 update law

metric
→ pairwise distance와 metric law

impedance
→ path·dynamics·frequency-dependent resistance

energy/potential
→ candidate별 scalar
```

원문이 실제로 가장 가까이 정의한 것은 마지막이었다.

이번 작업에서 첫 번째 큰 교정은 이것이었다.

> 이름이 가리키는 존재론보다 실제 연산이 더 좁을 수 있다.

## 권위 없는 영향과 지속 상태는 같은 concept가 아니었다

처음에는 `Persistent Non-Authority`를 새 concept 후보처럼 생각했다.

그러나 extraction을 작성하면서 최소 다음이 갈라졌다.

```text
C0006
= 권위 없이 후보·행동 편성에 영향을 주는 relation

EffectiveRoutingField
= 현재 후보를 기울이는 condition/state/function 후보

PlasticState
= 다음 상태까지 지속 가능한 내부 causal state 후보

PlasticUpdateOperator
= state delta를 산출하는 transition rule 후보

PlasticStateDelta
= 실제 적용된 변화 payload 후보

PlasticResidue
= update 뒤 남은 causal state 후보

PlasticUpdateSignature
= update의 source·범위·지속 metadata 후보

PlasticTraceRecord
= 변화에 관한 별도 diagnostic record 후보

ShapingClaimSignature
= authority-facing 변화 주장 metadata 후보

𝔄
= applied event·evidence·attribution·responsibility register
```

이것들을 모두 `persistent non-authority`라고 부르면 또 하나의 바구니가 생긴다.

이번 장이 준 답은 하나의 새 물체가 아니라:

> 빈자리를 몇 개의 서로 다른 타입으로 물어야 하는가

에 가까웠다.

따라서 후속 cluster의 질문도 바뀌어야 한다.

```text
persistent + non-authoritative를 만족하는 후보들이
하나의 genus인가?

아니면 state·transition·residue·record가 공유하는
교차 특성 조합인가?
```

새 C-ID가 나오지 않아도 이 질문이 닫히면 cluster는 성공한다.

## field-direct와 knob-only를 한 모델로 봉합하지 않았다

원문은 두 경로를 동시에 제시한다.

```text
Reading A
E_{ΦΩ}(v)
→ candidate별 P_call 직접 재가중

Reading B
E_{ΦΩ}
→ K_ctrl summary
→ allowed knobs
→ Norm
→ P_call
```

처음에는 둘을 같은 설명의 수식형과 문장형으로 볼 수 있었다.

하지만 실제로는 다른 policy class일 수 있다.

field-direct 모델은 후보별 정서·persona·접근 bias를 직접 표현할 수 있다. strict knob-only 모델은 threshold·exploration·width·delay 같은 제한된 노브만 바꾼다.

둘은 표현력과 정보 용량, 권한 방화벽의 성질이 다르다.

그리고 원문에는 둘을 잇는 함수가 없다.

```text
K_ctrl = Summarize(E, ctx, policy)
P_call = Norm(K_open, K_ctrl, gate)
```

가 정의되지 않았다.

이번 intake에서는 어느 쪽이 옳은지 고르지 않았다. 같은 원문 안의 두 정책 해석을 별도 후보로 남겼다.

## M_shape는 남은 흔적이 아니었다

`M_shape`이라는 이름은 medium이 얼마나 변형됐는지 재는 것처럼 보인다.

하지만 직접 정의는 연속한 `P_call` 분포의 divergence다.

```text
M_shape(t)
= D(P_call,t, P_call,t-1)
```

이 값은 `E`만의 변화가 아니다.

```text
K_open
context
candidate support
gate
control knobs
```

가 바뀌어도 달라질 수 있다.

또:

```text
P0 → P1 → P0
```

처럼 원래 분포로 돌아와도 누적 divergence는 양수가 될 수 있다.

따라서:

```text
routing path length
≠ endpoint persistence
≠ PlasticResidue
```

다.

이번 작업에서 `M_shape`를 `EffectiveRoutingShift`와 비교한 이유는 원문 이름을 갈아 끼우기 위해서가 아니다. 직접 연산이 무엇을 측정하고 무엇을 측정하지 못하는지 보존하기 위해서다.

## ShapingSig는 변화 자체의 흔적이 아니었다

이 장에서 가장 위험한 혼합은 `ShapingSig`였다.

```text
ShapingSig
= MetricEpoch
+ Window
+ Region
+ LinkedAudit
```

이 구조는 어느 version·시간·영역·audit pointer 아래 성형을 주장하는지 묻는다. 좋은 provenance precursor다.

그러나 다음은 없다.

```text
source kind
direction
magnitude
reversibility
persistence
decay
consolidation
```

그래서:

```text
ShapingSig
= authority-facing claim metadata

PlasticUpdateSignature
= internal transition description candidate
```

로 분리했다.

또 `PlasticTrace`라는 말도 둘로 갈랐다.

```text
PlasticResidue
= 실제로 남아 이후 causality를 바꾸는 state

PlasticTraceRecord
= 그 변화에 관한 별도 기록
```

기록되지 않은 causal residue가 있을 수 있다. 기록이 있어도 불완전하거나 잘못될 수 있다.

```text
residue
≠ record
```

이 분리는 이번 장에서 가장 중요한 수확 가운데 하나였다.

## audit 규칙이 존재론으로 커지는 순간

원문의 안전한 문장은 다음이다.

```text
감사 연결이 없는 shaping claim은
SSOT/worldline을 건드릴 자격이 없다.
```

그러나 강한 정리 문장은 다음처럼 읽힐 수 있다.

```text
나는 변했는데 로그가 없다
→ 정의역상 불가능
```

이 둘은 다르다.

```text
change occurred
≠ change claim is auditable
≠ external receipt exists
≠ normative debt exists
```

사적 학습·습관화·생각·꿈·정서 변화는 공적 권위 원장을 만들지 않고도 존재하고 이후 행동을 바꿀 수 있다.

그래서 남긴 규칙은:

```text
No Silent Certified Shaping
```

이지:

```text
No Unlogged Internal Change
```

가 아니다.

권위가 없다는 것은 존재하지 않는다는 뜻이 아니다. 기록되지 않았다는 것도 인과적 흔적이 없다는 뜻은 아니다.

## No Self-Warrant는 No Information이 아니다

Anti-Oracle도 같은 교정을 요구했다.

```text
felt certainty
cannot certify its own external claim
```

은 강하게 남길 수 있다.

그러나:

```text
felt signal
has no predictive information
```

까지 말할 수는 없다.

불길함·직감·유창함·익숙함은 숨은 외부 단서나 학습 이력을 요약할 수 있다. 조사 우선순위·주의·검증 질문을 바꿀 수 있다.

그 정보량과 외부 정확성은 독립적으로 검증해야 한다.

```text
signal
→ hypothesis / priority / caution
→ independent check
→ evidence-backed update or Unknown
```

이 경로는 감정을 무력한 화면으로 만들지도 않고, 감정을 진실 토큰으로 만들지도 않는다.

## 외부 감사에서 배운 제한

외부 연구는 `ΦΩ`를 검증하지 않았다.

오히려 다음을 분리하게 했다.

```text
PhenomenalEpisode
≠ report
≠ confidence
≠ meta-d′
≠ PCI
≠ neural decoding
```

기억·engram·reconsolidation 연구는 경험과 함께 일어난 처리 뒤 미래 접근·행동·연합이 달라질 수 있음을 보여 준다.

하지만:

```text
past experience itself was stored
phenomenal character itself wrote the change
```

를 직접 보여 주지는 않는다.

현재 많은 관측은 다음 두 모델을 분리하기 어렵다.

```text
Model A
PhenomenalExperience
→ PlasticUpdate

Model B
LatentProcessing
→ PhenomenalExperience
LatentProcessing
→ PlasticUpdate
```

따라서 현행 Bridge에서도 experience 자체의 writer 인과를 자동 선언하지 않았다.

## Chapter 11의 실제 종점

처음 질문은:

```text
ΦΩ가 빈자리를 채우는가.
```

였다.

작업 뒤 답은:

```text
routing relation에는 부분적으로 답한다.

persistent state에는 답하지 않는다.
update operator에도 답하지 않는다.
residue와 record도 구분하지 못한다.
Ghost handoff도 주지 않는다.
```

가 됐다.

그래도 실패만은 아니다.

`NEWQUAL22`는 이 저장소에서 처음으로:

```text
Influence without Warrant
```

를 candidate distribution 수준에 형식화했다.

그리고 Chapter 11 전체는 그 형식을 매질·경험·기억·가소성·자아 연속성으로 과장하지 않기 위해 필요한 타입 경계를 제공했다.
