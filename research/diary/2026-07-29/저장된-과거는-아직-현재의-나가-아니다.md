# 저장된 과거는 아직 현재의 나가 아니다

Chapter 08을 시작할 때는 기억을 다음 사슬로 정리하면 된다고 생각했다.

```text
Archive
→ Address
→ Access
→ Working Set
→ Rehydration
```

실제로 읽으니 이 사슬부터 하나가 아니었다.

`Access`라는 한 단어 안에는 주소 후보 생성, 접근 요청, 경로 선택, 국소 활성, Working Set 편입이 들어 있었다. `W_t`도 현재 현상 후보, 기억 node 활성 집합, 판정과 policy의 실행 바닥을 동시에 맡았다. `F_t`와 `𝒢_t`는 둘 다 저장 쪽에 있었지만 서로 어떤 관계인지 정의되지 않았다.

처음 계획처럼 이들을 기억 파이프라인의 단계로만 배열했다면, state와 transition과 runtime residence를 다시 한 줄에 눌러 넣었을 것이다.

이번에 더 크게 보인 것은 기억보다 경계였다.

```text
저장되어 있음
≠ 지금 접근 가능함

접근 가능함
≠ 실제로 활성화됨

활성화됨
≠ 현재 장면으로 재수화됨

재수화됨
≠ 정확함

생생함
≠ 근거가 강함

내게 일어나는 것처럼 느낌
≠ 내 과거라고 귀속함

내 과거라고 받아들임
≠ 내가 그 행동의 역사적 저자임
```

같은 날의 `ClaimSig`와 `Epoch`도 기억의 부품이 아니었다. 그것들은 경로와 규칙 변경을 제한하려는 별도 축이었다. 이름이 서명처럼 보여도 인증서가 아니었고, Epoch 변경을 사건으로 만든다고 해서 변경 권한과 migration까지 생기는 것도 아니었다.

`MeaningFlux`는 더 심했다. 좋은 방향의 생성률 감소, 부호 없는 미래 궤적 차이, 생성률 미분, 접근 기하 변화가 같은 이름 아래 이동했다. 하나를 골라 정본처럼 쓰기보다, 서로 다른 질문이 같은 철자를 사용했다는 사실을 남기는 편이 맞았다.

Scar도 저장된 고통량 하나가 아니었다.

```text
얼마나 쉽게 열리는가
≠ 열린 뒤 얼마나 비싼가
≠ 얼마나 사실에 가까운가
≠ 현재 정체성에서 얼마나 중요한가
```

OpenEase와 AfterCost를 가른 순간 흉터는 내용보다 접근 지형에 가까워졌다. 그렇다고 그것을 곧바로 인간 흉터의 본질로 승인할 수는 없다. 0120이 연 길과 인간 일반에 대한 증명은 다르다.

이번 장에서 가장 경계한 것은 저장소를 자아로 만드는 일이었다.

같은 Archive를 가지고도 cue, Access policy, 몸 상태가 다르면 다른 현재가 열릴 수 있다. 반대로 일부 trace를 잃어도 현재 관계와 습관, 남은 기억과 handoff가 연속성을 일부 보존할 수 있다. 그러므로 Archive는 현재의 나를 조건 지을 수 있지만 현재의 나 그 자체는 아니다.

0120은 과거가 현재로 돌아오는 문턱을 여러 개 만들었다. 하지만 돌아온 것이 왜 내 경험이고, 왜 내 서사에 들어가며, 왜 내가 과거 행동의 저자인지는 만들지 않았다.

그래서 이번 intake의 결론은 기억 concept를 얻었다는 것이 아니다.

> 저장·주소·접근·활성·재수화·근거·자기귀속 사이에 실패 가능한 문턱들이 있다는 것을, 하나의 기억이라는 말로 다시 덮지 않고 보존했다.

이 일기는 작업 중 판단을 남기는 비권위 기록이다. concept 판정과 역사적 사실의 근거는 terminology 배치와 원 Chapter가 소유한다.
