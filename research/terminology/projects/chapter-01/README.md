# Chapter 01 Intake

이 디렉터리는 `chapters/chapter-01-ionstar-origin-0101-0103.md`를 chronology의 첫 terminology 입력 배치로 복구한다.

권한과 산출물은 다음 파일이 소유한다.

- `scope.md`: 조사 범위와 출처별 주장 권한
- `extraction-map.md`: 중립 후보 58개와 선행 대조
- `basic-term-list.md`: 역사 명칭·기호 색인
- `touched-concepts.md`: 기존 C-ID와 HOLD cluster에 대한 실제 대조

Chapter 01의 `LINEAGE`와 `BRIDGE`는 후대 concept의 옛 이름이 아니다. `PRECURSOR / RELATED / HOLD`로만 연결하며, 새 C-ID나 synonym `MERGE`는 별도 cluster 분석 없이는 허용하지 않는다.
