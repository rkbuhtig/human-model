# Chapter 02 Terminology Intake — Scope

## 1. 조사 질문

Chapter 02에서 동일한 명칭이나 기호가 서로 다른 책임을 가리킨 지점을 풀어, 현재 연구에서 독립적으로 검토해야 할 개념 후보를 식별한다.

이 프로젝트는 Chapter 02의 사전을 만들지 않는다. Chapter 02는 입력 배치이며, 살아남는 개념은 이후 `termbase/concepts/`가 소유한다.

## 2. 주 입력

- `chapters/chapter-02-event-irreversibility-0104-0111.md`

Chapter 02는 2026-01-03/04부터 01-11까지의 AXIOM37·EVENT 계보를 복원한 역사 연구 문서다. 동일 철자가 epoch에 따라 다른 역할을 한 사실, 과잉 통합과 재분리의 흐름, 현재 Chapter synthesis를 조사 입력으로 사용한다.

## 3. 보조 입력

Chapter 02 안에서 직접 참조하거나 같은 명칭군의 경계를 확인하는 자료만 보조 입력으로 사용한다.

- Chapter 02가 복원한 `A37`, `SSOT`, `EOE`, `RT02`, `JOT07`, `INT8`, `PHYS3/4`, `EVT1–4` 계열
- 같은 명칭의 이후 변화를 확인하는 다른 Chapter
- 현재 연구 사용을 별도로 조사하는 `projects/current-research/`

다른 Chapter나 현재 연구의 내용은 Chapter 02의 의미를 자동 승인하지 않는다. 서로 다른 입력 배치로 보존한 뒤 concept 단계에서 대조한다.

## 4. 출처별 주장 권한

| 출처 | 이 프로젝트에서 할 수 있는 주장 | 이 프로젝트에서 할 수 없는 주장 |
|---|---|---|
| Chapter 02 원문 복원 | 어떤 명칭이 어느 epoch에서 어떤 역할을 가리켰는가 | 인간 내부에 동일한 단계·객체가 존재한다 |
| Chapter synthesis | 여러 원문에 걸친 과적재와 재분리의 해석적 요약 | 각 후보가 현재 독립 인간 개념이라는 확정 |
| 엔진 문서 | writer, store, cycle, lock 등 구현 책임의 차이 | 구현 분리가 인간 ontology라는 주장 |
| 다른 Chapter | 같은 후보가 다른 지층에서도 재등장하는지 | Chapter 02의 후보를 자동 KEEP 처리 |
| 현재 연구 입력 배치 | 현재 설명에 실제로 필요한 구분 | 역사적 기원이나 당시 의미의 확정 |

## 6. 반드시 보존할 Chapter 02 후보

`Commit` 계보에서 다음 역할을 조용히 줄이거나 다른 폴더 소관이라는 이유로 제외하지 않는다.

- 밖으로 말한 것
- 행동을 선택한 것
- 사건이 실제로 발생한 것
- 몸에 흔적이 남은 것
- 기억으로 굳은 것
- 의미가 확정된 것
- 원장에 기록된 것

추가로 다음 충돌을 반드시 표시한다.

- `Event_hardening ≠ Event_position ≠ Event_phase ≠ Event_timepoint`
- `JOT_cycle ≠ JOT_store ≠ SSOT`
- 0109의 Event 뒤 Quench와 0110의 Quench를 포함한 Event
- `Potential ≠ Irreversible`
- CandidatePack과 결론·적용의 비동일성
- 지속 흔적과 상태·진실 갱신 권한의 비동일성

## 7. 이 배치가 만드는 산출물

이 배치에서는 concept ID, 정의, 권장 명칭, glossary를 만들지 않는다.
