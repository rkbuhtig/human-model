# Chapter 04에서 개설하거나 갱신한 concept

이 문서는 Chapter 04 배치가 두 번째 concept cluster 분석에서 건드린 C-ID와, C-ID를 열지 않은 인접 후보의 목적지만 기록한다. 정의와 명칭을 복제하지 않는다.

## 새로 개설

- `C0006`
  - `X-CH04-003` Episode pressure
  - `X-CH04-005` Gift influence와 felt debt
  - `X-CH04-015` delayed causal lane
  - `X-CH04-017` finite-search influence
  - `X-CH04-018` same-tick 자기확증 차단

  현재 선택·Commit·persistent writer를 직접 행사하지 않으면서 이후 탐색·비교·후보 발견을 바꾸는 비권위적 인과 역할로 분석했다. Gift가 influence를 만들 수 있어도 valid obligation이나 복종 의무를 발급하지 않는 대비를 사용했다.

- `C0007`
  - `X-CH04-004` interaction work
  - `X-CH04-023` `Work_cov`의 실제 scan·compare work 역할

  노동을 호출하거나 배분한 사실, 실제 수행 노동, 자원 지출, 수행 기록을 분리했다.

- `C0008`
  - `X-CH04-024` No-discount와 Throttle 아래 실제 지출 경계
  - `X-CH04-014`·`X-CH04-023`·`X-CH04-024`의 `Spend` 역할

  수행한 작업의 actual expenditure를 capacity·envelope·slack·작업량·회계 기록과 분리했다.

- `C0009` — `ENGINE-ONLY`
  - `X-CH04-019` influence·search provenance 공백
  - `X-CH04-026` Accounting value·stage·receipt와 MeaningFlux의 재압축 실패

  수행·지출의 계보와 귀속을 보존하는 기술 기록으로 유지한다. 인간 내부에 별도 accounting record가 존재한다는 인간 현상 근거는 없다.

## 경계 재압축 이력에 사용

- `C0006`
  - `X-CH04-028` Story add-only capability regression
  - 비권위적 영향과 직접 후보 생성 권한이 한 branch에서 다시 섞인 이력으로 기록했다.
- `C0009`
  - `X-CH04-026` R05 `A`와 MeaningFlux 이중 배치
  - readout, execution result, accounting stage, receipt의 경계가 다시 섞인 이력으로 기록했다.

## 경계 확인에 사용했지만 C-ID를 열지 않은 후보

- `X-CH04-007` Alignment
  - 현재 상태 readout, 회복 방향, 조율 목표가 같은 concept인지 근거가 부족하다.
- `X-CH04-009` Rhythm
  - readout 좌표와 scheduler 권한이 역사적으로 충돌했으므로 별도 cluster로 남긴다.
- `X-CH04-016` Policy와 `k`·`ρ`·budget·ReorderHint
  - 역사적 운영 노브이며 C0006의 인간 concept 특성으로 승인하지 않는다.
- `X-CH04-020` Priority와 `X-CH04-021` GateBias
  - 현재 끌림 방향과 다음 tick control bias를 분리했지만 독립 인간 concept를 열 인간 장면 근거가 부족하다.
- `X-CH04-022` Coverage
  - 현재 접근 범위, attention span, self-boundary, 장기 access policy의 경계가 닫히지 않았다.
- `X-CH04-023` CovState·delayed update 역할
  - C0007에는 실제 `Work_cov` 역할만 연결했다. persistent update target은 concept보다 구현 transition 후보로 보류한다.
- `X-CH04-025~027` X/R/U/A와 Residence / Flow / Attribution
  - 역사적 residence audit와 실패 기록으로만 유지한다. 현재 ontology·schema·C-ID로 승격하지 않는다.
- `X-CH04-030` outcome record·observation receipt·EvidenceLink
  - 현재 Chapter에 실제 계약이 없으므로 C0004·C0009와 자동 통합하지 않는다.

## 근거 권한

Chapter 04의 질문·침묵·증여·Episode pressure·actual-work 사례는 분석 이전부터 존재한 저장소 내부 이론 사례다. 독립 관측 자료나 인간 일반에 대한 경험적 검증 자료는 아니다. X/R/U/A의 네 칸은 C-ID 분류표로 사용하지 않고, 그 실패가 드러낸 지속성·파생·영향·시점·writer·귀속 질문만 특성 분석에 사용했다.
