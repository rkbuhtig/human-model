# Chapter 07 Terminology Intake — Scope

## 1. 조사 질문

Chapter 06이 `Grounds`와 `Influence`를 분리한 뒤, Chapter 07이 인간 현상학을 한 번 전면 격리했다가 같은 날 밤 다시 행동 가능한 원인으로 복권한 과정을 추출한다.

```text
현재 체험·서사·사랑·활력
≠ 판정 Grounds
≠ irreversible write authority

그러나

Grounds가 아님
≠ 비원인
≠ 장식
≠ 다음 행동에 무관함
```

중심 질문은 다음과 같다.

```text
ViewOut 봉인은 무엇을 보호했고 무엇을 과잉 차단했는가?
Coverage는 현재 접근 범위인가, 증거 범위인가, 지속 상태인가?
Story·Φ·Love가 Grounds 없이 어떤 인과 역할을 맡았는가?
부분 Coverage가 왜 Fog·Ψ·Reporter를 요구한다고 모델링되었는가?
Cut-1과 Cut-2는 선택·행동·기록·적용 중 무엇을 실제로 갈랐는가?
Ego as Compression은 현재 장면과 통시적 자아 중 어디까지 설명하는가?
지속하지만 비권위적인 재료들은 하나의 concept인가, 서로 다른 genus가 공유하는 관계 문제인가?
```

이번 intake는 Chapter 07의 답을 현재 정본 인간 ontology로 승인하지 않는다. 0119에서 한 이름이 어떤 역할을 맡았고, 같은 날 어떤 충돌·교정·공백이 생겼는지를 중립 후보로 추출한다.

## 2. epoch와 연대기 독해

0119는 한 날짜 안에서도 모델 체제가 크게 바뀐다. 단순한 최신판 우선이나 한 줄 계보로 읽지 않는다.

```text
MORNING19
SLOT19
→ LINK19
→ NORM19 / VESSEL19

NIGHT19
CLEAN19
↔ LOG19 base + vA0.2 + vA0.3 + vA0.4
```

### 2.1 MORNING19

- `SLOT19`: 0117 현상학을 `ViewOut` payload slot으로 전면 재작성한다.
- `LINK19`: Lens·Love·Γ·View가 current Grounds·Event/Quench·ledger로 새는 경로를 LINT와 forbidden edge로 닫는다.
- `NORM19` / `VESSEL19`: Constitution·Vessel·§6·Linker를 한 실행 헌법 아래 재배치한 합본 계열이다.
- 오전 Constitution의 `M1~M4`는 역할 문장과 epoch를 함께 적는다.

### 2.2 NIGHT19

- `CLEAN19`: Default Fog·Reporter·Polarizer·Ego Compression·Two-Cut의 standalone integrated form이다.
- `LOG19`: base rewrite 뒤 vA0.2~vA0.4 addendum가 교정 논리를 보존한다.
- 저장 시각만으로 `LOG19 → CLEAN19` 또는 `CLEAN19 → LOG19`의 단일 textual descent를 확정하지 않는다.
- 밤 UC의 `M1~M3`는 오전 번호와 같은 법칙이 아니다.

### 2.3 epoch 표기

같은 철자나 번호가 다른 역할을 맡으면 basic term list에서 다음처럼 분리한다.

```text
M1@MORNING19
M1@NIGHT19

M2@MORNING19
M2@NIGHT19

π@STORY19
A@LENS19
W@LENS19
F@VITALITY19
```

번호·기호가 같다는 이유로 synonymy나 직접 승계를 주장하지 않는다.

## 8. 핵심 비동일성

### 8.1 surface·influence·grounds

```text
View / Φ / Story / Love
≠ external fact Grounds
≠ Warrant
≠ irreversible writer authority

non-grounding
≠ noncausal
≠ unreal
```

C0006은 `ViewOut`, `StoryField`, `Φ`, `Dream` 같은 entity의 상위 바구니가 아니다. 이들이 비권위적으로 영향을 주는 **관계**와 대조한다.

### 8.2 Coverage

```text
현재 접근 가능한 범위
≠ 세계에 증거가 존재하는 범위
≠ 판정이 확보한 증거 범위
≠ 지속하는 CovState
≠ Chapter 08 Working Set
```

Coverage가 확장되려면 실제 scan·compare 노동이 필요하다는 runtime 규칙과, 인간 concept로서의 접근 범위를 자동 통합하지 않는다.

### 8.3 지속하지만 비권위적인 후보군

```text
JOT material
CovState
PlasticTrace
M^plast
```

은 `persistent + non-authoritative`를 공유할 수 있지만 같은 concept라고 가정하지 않는다.

```text
unresolved durable record
≠ persistent perceptual/access state
≠ adaptation trace
≠ memory/plasticity state
```

이번 배치는 persistence와 authority의 직교 문제를 기록하고, 각 후보의 genus가 닫힐 때까지 `HOLD`한다.

### 8.4 선택·행동·귀속

```text
Ψ candidate exists
≠ candidate selected
≠ Cut-1 condensation
≠ BodyAuthorization
≠ PerformedAction
≠ external outcome
≠ outcome observation
≠ EvidenceLink
≠ Certification
≠ Cut-2 application
≠ Narrative adoption
```

Cut-1을 C0001의 synonym으로, Cut-2를 C0002·C0004 또는 application의 단일 synonym으로 승인하지 않는다.

### 8.5 자아

```text
Reporter
≠ Editor
≠ candidate generator

Ego as Compression
≠ current Ghost runtime
≠ diachronic self
≠ self-adoption
≠ authorship handoff
```

Chapter 07은 identity/self 영역을 강하게 열지만 이번 intake에서 새 C-ID를 발급하지 않는다.

### 8.6 비용·의무

```text
candidate generation work
≠ attention switching
≠ metabolic compute cost
≠ actual resource expenditure
≠ deferred repair
≠ transferred burden
≠ normative obligation
```

`Optionality Cost`가 실제 계산·탐색의 비무상성을 포착하더라도 모든 내부 연산을 Receipt→σ→Bill obligation으로 번역하지 않는다.
