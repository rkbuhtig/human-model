# C0008

## 작업 설명

행동·탐색·비교·수리 같은 수행에서 실제로 소비된 가용 능력·에너지·회복 여유를 다룬다. 가용 stock, 최대 출력 envelope, 일회성 slack, 수행 노동의 내용과 양, 체감 부담, 실제 수리 결과, 비용 기록과 합치지 않는다.

## 현재 판정

`KEEP`

이 판정은 현재 인간 연구에서 무엇을 했는가, 무엇이 실제로 소모됐는가, 무엇이 덜 괴롭게 느껴졌는가, 무엇이 실제로 수리됐는가를 구별하는 어휘가 필요하다는 뜻이다. 인간의 피로·노력·회복이 하나의 `Spend` scalar로 측정된다는 뜻은 아니다.

## 연결된 입력 후보

- `X-CH03-042` — 실제 행동·탐색·후보 생성에 자원이 지출됨
- `X-CH04-024` — 수행한 작업은 정가로 귀속되지만 총 작업량은 줄일 수 있음
- `X-CH06-001` — 현재 감당 요구·실제 수리·체감 완화가 갈림
- `X-CH06-008` — 현재 체감 부담 감소와 실제 잔여·lock·margin 개선이 갈림

다음 후보는 경계를 확인할 때 사용하지만 자동 통합하지 않는다.

- `X-CH03-038` — 현재 상태에서 파생된 slack
- `X-CH03-039` — 반복 가능한 자원 stock 또는 capacity
- `X-CH03-041` — 단위 시간 최대 출력 envelope
- `X-CH04-014` — 미사용 출력의 일회성 slack
- `X-CH04-023` — 실제 작업에 결박된 coverage 갱신
- `X-CH03-035` — WorkEvent·Billing 기록
- `X-CH06-002` — 전망 완화 차액의 별도 계상 시도
- `X-CH06-026` — 운영 비용과 raw 판정량이 LedgerCore에 재혼합된 실패

## 코퍼스 확인 대비 사례

Chapter 04는 좋은 상호작용이 비용을 없애는 것이 아니라 비용의 형태·시점·부담 주체를 바꿀 수 있다고 서술한다. 또한 과열 구간에서 후보 폭과 총 작업량을 줄이는 Throttle을 허용하지만, 실제로 수행한 작업과 얻은 변화의 비용을 설명으로 지우지는 못하게 한다.

```text
less work performed
≠ performed work became free

available capacity
≠ actual expenditure
≠ unused slack
```

Chapter 06은 체감 완화·수리·자원 소비를 추가로 분리한다.

```text
felt burden decreased
≠ repair work was performed
≠ residual / lock / margin improved
≠ actual resource expenditure decreased
```

`X-CH06-001`은 Pressure·Repair·Relief를 가르고, `X-CH06-008`은 CosmeticRelief와 TrueRelief를 가른다. 이 대비는 C0008이 주관적 부담감이나 수리 결과가 아니라 실제 소비를 다룬다는 점을 보강한다.

`X-CH06-002`의 RiskCarry는 현재 완화의 차액을 다른 축에 남기려는 계보 근거지만 실제 자원 지출의 직접 사례로 사용하지 않는다. `X-CH06-026`도 긍정 근거가 아니라 비용과 판정량을 재압축한 실패 사례다.

이 사례들은 저장소 내부 이론 자료이며 독립 관측 자료나 인간 일반에 대한 경험적 검증 자료는 아니다.

## 상위 개념과 관계

- 상위 개념 후보: 수행으로 인한 실제 자원 소비
- `C0005`와의 관계: 체감 부담이나 노력감은 C0008의 직접 측정값이 아니며 실제 소비와 다르게 변할 수 있다.
- `C0007`과의 관계: C0007은 실제 수행된 활동을, C0008은 그 수행으로 소비된 자원을 다룬다.
- `C0009`과의 관계: C0009는 지출 사실과 귀속을 보존하는 기록이며 지출 자체가 아니다.
- `X-CH03-039`와의 관계: resource stock은 소비 가능한 상태이고 actual expenditure와 별도다.
- `X-CH03-041`과의 관계: output envelope는 가능한 최대량이며 actual use와 별도다.
- `X-CH04-014`와의 관계: slack은 actual expenditure 뒤 계산되는 파생 여유다.
- `X-CH06-001`과의 관계: repair demand와 repair work, 실제 resource expenditure는 각각 별도 판정이다.
- `X-CH06-006`·`X-CH06-026`과의 관계: raw residual은 판정량이며 operational expenditure와 같은 단위나 concept로 승인하지 않는다.

## 이 구분이 보존하는 것

실제로 무엇을 했는가, 그 일을 감당하기 위해 무엇이 소모됐는가, 현재 얼마나 힘들게 느끼는가, 문제가 실제로 얼마나 수리됐는가를 구별한다. 이 경계를 잃으면 체감이 편해졌다는 이유로 비용과 미해결 문제가 함께 사라졌다고 보거나, 많은 일을 했다는 이유만으로 항상 같은 피로·손상을 가정하거나, 작업량을 줄였다는 이유로 이미 수행한 노동의 비용까지 없었던 것으로 처리하게 된다.

## 경계 재압축 이력

- 무너진 경계: 실제 자원 지출 ≠ 수행 노동 ≠ 비용 회계 기록
- 위치: Chapter 03의 `WorkEvent`·Billing·Spend 묶음과 `X-CH03-035`
- 재압축 방식: 수행된 노동, 그 비용, 그 비용을 증명하는 기록이 한 묶음으로 서술됨
- 발생한 손실: 활동량·소비량·기록 존재를 독립적으로 판정하기 어려워짐

- 무너진 경계: operational expenditure ≠ evidence-side residual
- 위치: Chapter 06의 `LedgerCore`, `X-CH06-026`
- 재압축 방식: Spend·heat·운영 제약과 `ΔQ⊥_raw`·dm_phys 같은 판정량을 같은 core output에 모음
- 발생한 손실: 수행 비용이 줄었는지, schema-relative 문제가 줄었는지, persistent state가 바뀌었는지를 독립적으로 판정하기 어려워짐

## 정의 초안

행동·탐색·비교·수리 같은 수행 때문에 가용 능력·에너지·회복 여유가 실제로 소비된 것으로서, 수행 활동 자체, 현재 체감 부담, 실제 수리 결과, 가용 stock·envelope·slack 및 그 지출에 관한 기록과 별도로 판정되는 것.

## 명칭

- 권장 용어: 미정
- 작업용 서술: 실제 자원 지출
- 역사적 명칭: `F_use`, `Spend`, actual use

단일 scalar 표현을 이 concept의 본질로 승인하지 않는다.

## 남은 불확실성

- 신체 에너지·주의 자원·사회적 수리 비용을 같은 상위 concept로 둘 범위
- 주관적 노력감과 실제 자원 소비를 분리할 독립 관측 근거
- 회복 가능 비용과 비가역 손상을 별도 concept로 나눌 조건
- actual repair와 expenditure의 인과 관계를 어떤 provenance로 결박할지
