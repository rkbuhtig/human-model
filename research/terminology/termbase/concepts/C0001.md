# C0001

## 작업 설명

여러 가능한 행동 경로 가운데 하나가 이후 수행 대상으로 채택되는 상태를 다룬다. 이 파일은 선택의 이유, 의도, strategy configuration record, 명령 출력, 시도, 수행, 외부 발생을 하나의 선형 단계로 확정하지 않는다.

## 현재 판정

`KEEP`

이 판정은 현재 인간 연구의 어휘에서 실제 수행과 구별되는 선택 상태를 유지할 가치가 있다는 뜻이다. 인간 내부에 독립된 선택·전략 채택 모듈이 경험적으로 입증됐다는 뜻은 아니다.

## 연결된 입력 후보

- `X-CH02-001` — 행동 후보가 이후 수행 대상으로 선택됨
- `X-CURR-001` — 여러 행동 후보 가운데 이후 행동 경로가 선택됨
- `X-CH05-033` — Decision과 ActionOut·actual occurrence·world outcome이 갈림
- `X-CH06-036` — Choice·StrategyAdoption·ActionOut·PerformedAction·ExternalOutcome 분리 요구

다음 후보는 대비에 사용하지만 이 concept로 자동 통합하지 않는다.

- `X-CH02-002` — 외부 표현
- `X-CH02-003` — 외부 발생
- `X-CURR-002` — Intent / Attempt / Performance 분리
- `X-CURR-003` — 수행과 ActionOccurrence의 경계
- `X-CH06-012~014` — strategy knob configuration Receipt와 저장 경로
- `X-CH06-034` — configuration Receipt가 ActionOut보다 먼저 생성됨
- `X-CH06-035` — body authorization·veto·execution state 부재

## 특성 분석

| 특성 | 판정 | 근거 권한 | 출처와 판단 |
|---|---|---|---|
| 둘 이상의 가능한 행동 경로를 전제한다 | 본질 | 계보 + 현재 사용 | `X-CH02-001`, `X-CURR-001` |
| 하나의 경로가 이후 수행 대상으로 채택된다 | 본질·차별 | 계보 + 현재 사용 | 후보가 존재하는 것과 선택된 것을 구분한다. Chapter 06의 `StrategyAdoption` 역할도 이 경계에 포함한다. |
| 실제 수행이나 외부 발생 없이도 성립할 수 있다 | 본질·차별 | 코퍼스 확인 인간 장면 | Chapter 02 §3.2의 같은 `연락하지 않음` 아래 안정된 noop과 문턱 미달·억제가 갈리는 장면은 표면 비행동이 내부 선택 상태를 결정하지 못함을 보여준다. |
| 선택된 전략을 기록한 Receipt와 동일하지 않다 | 본질·차별 | 계보상 반증 | Chapter 06의 configuration Receipt는 ActionOut보다 먼저 mint되며 선택의 payload 기록이지 선택 상태 자체가 아니다. |
| 외부로 전달되는 ActionOut과 동일하지 않다 | 본질·차별 | 계보상 반증 | Chapter 05·06은 Decision과 ActionOut을 별도 단계로 둔다. 선택이 있어도 명령 출력이 없거나 달라질 수 있다. |
| 선택 이유가 하나의 원인으로 환원된다 | 제외 | 근거 없음 | Ghost, Editor, Will, Map, 자원 제약이 경쟁 설명으로 남아 있으므로 정의에 넣지 않는다. |
| Intent → Attempt → Performance의 고정 순서를 가진다 | 엔진 의존 후보 | 현재 사용 | RFC 0001의 계약 경계는 현재 아키텍처 구분이며 인간 현상 특성으로 사용하지 않는다. |
| 반드시 body authorization을 거쳐야 성립한다 | 제외 | 역할상 반증 | 신체 허가가 필요할 수 있는 것은 수행 단계이며, 경로 채택 자체의 필수 조건으로 확인되지 않았다. |

## 코퍼스 확인 대비 사례

Chapter 02 §3.2는 같은 표면 행동 `연락하지 않음`을 다음처럼 나눈다.

- 경계를 존중해 안정된 noop을 선택한 경우
- 두려움 때문에 Probe 문턱을 넘지 못한 경우
- 분노를 억제해 Residual이 남은 경우

이 대비는 외부 비행동만으로 선택·억제·수행 실패를 합칠 수 없음을 보여준다. 해당 사례는 저장소 내부에서 구분을 설명하기 위해 작성된 사례이며 인간 일반에 대한 독립 관측 증거는 아니다.

Chapter 06은 다음 사슬을 추가로 분리한다.

```text
strategy adopted
≠ configuration Receipt minted
≠ ActionOut emitted
≠ action performed
≠ external outcome
```

따라서 전략이 채택됐다는 사실은 기술 payload의 존재나 실제 수행·결과를 자동 보증하지 않는다.

## 상위 개념과 관계

- 상위 개념 후보: 행동 결정 상태
- `C0002`와의 관계: 선택은 외부 발생보다 선행할 수 있지만 발생을 보장하지 않는다.
- `C0003`과의 관계: 선택은 세계 결과가 아니다.
- `C0004`와의 관계: 선택 또는 strategy configuration에 관한 기록은 선택 자체가 아니다.
- `X-CH02-002`와의 관계: 외부 표현은 선택의 결과일 수 있으나 현재 자료만으로 별도 종적 개념인지 수행 과정인지 보류한다.
- `X-CH05-033`과의 관계: Decision 역할은 C0001에 병합하지만 ActionOut·occurrence·outcome은 각각 별도 판정한다.
- `X-CH06-012`와의 관계: configuration Receipt는 선택된 knob를 보존하는 ENGINE-ONLY 기록이며 C0001이 아니다.

## 이 구분이 보존하는 것

같은 외부 비행동 `연락하지 않음` 아래 안정된 noop, 두려움으로 인한 문턱 미달, 분노를 억제한 상태가 서로 다를 수 있음을 보존한다. 또한 전략을 채택한 것, 그 설정을 기록한 것, 명령을 출력한 것, 실제로 수행한 것을 구별한다. 이 경계를 잃으면 선택 후 수행되지 않은 경우와 애초에 선택되지 않은 경우가 사라지고, configuration Receipt나 ActionOut만으로 행동이 실제 수행됐다고 처리하게 된다.

## 정의 초안

둘 이상의 가능한 행동 경로 가운데 하나가 이후 수행 대상으로 채택된 결정 상태로, 그 선택을 보존한 기술 기록, 명령 출력, 실제 수행이나 외부 발생 없이도 성립할 수 있는 것.

## 명칭

- 권장 용어: 미정
- 작업용 서술: 행동 경로 선택
- 역사적 명칭: `Commit`, Decision, 일부 StrategyAdoption 역할

`StrategyAdoption`은 역할 연결이며 독립 모듈 명칭으로 승인하지 않는다. `Receipt`와 `ActionOut`은 이 concept의 명칭이 아니다.

## 경계 조화

- `H0002` — StrategyAdoption을 C0001에 병합하고 configuration Receipt·ActionOut·PerformedAction과 분리함

## 남은 불확실성

- 선택과 Intent가 항상 별개인지
- 안정된 noop을 적극적 선택으로 볼 조건
- 선택이 없는 문턱 미달과 선택 후 수행 실패를 어떤 근거로 가를지
- 장기 전략 채택과 단일 행동 경로 선택을 같은 상위 concept로 유지할 범위
