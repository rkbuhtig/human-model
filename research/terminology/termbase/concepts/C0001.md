# C0001

## 작업 설명

둘 이상의 가능한 행동 경로 가운데 하나가 이후 수행 대상으로 채택된 선택 상태를 다룬다. 선택의 이유, 의도, 장기 전략 채택, strategy configuration record, 명령 출력, 시도, 수행과 외부 발생은 이 concept에 자동 포함하지 않는다.

## 현재 판정

`KEEP`

현재 코퍼스는 실제 수행과 구별되는 행동 경로 선택을 독립적으로 유지할 대비를 제공한다. 이 판정은 인간 내부에 독립 선택 모듈이 경험적으로 입증됐다는 뜻이 아니다.

## 연결된 입력 후보

- `X-CH02-001` — 행동 후보가 이후 수행 대상으로 선택됨
- `X-CURR-001` — 여러 행동 후보 가운데 이후 행동 경로가 선택됨
- `X-CH05-033` — Decision과 ActionOut·actual occurrence·world outcome 분리

다음 후보는 관계 비교에 사용하지만 C0001과 synonym으로 통합하지 않는다.

- `X-CH06-036`의 `StrategyAdoption`
- `X-CURR-002`의 Intent / Attempt / Performance
- `X-CH06-012~014`의 configuration Receipt
- `X-CH06-034`의 Receipt-before-ActionOut

## 특성 분석

| 특성 | 판정 | 근거 권한 | 출처와 판단 |
|---|---|---|---|
| 둘 이상의 가능한 행동 경로를 전제한다 | 본질 | 계보 + 현재 사용 | `X-CH02-001`, `X-CURR-001` |
| 하나의 행동 경로가 이후 수행 대상으로 채택된다 | 본질·차별 | 계보 + 현재 사용 | 후보 존재와 선택 상태를 구분한다. |
| 실제 수행이나 외부 발생 없이도 성립할 수 있다 | 본질·차별 | 코퍼스 확인 사례 | 같은 표면 비행동 아래 안정된 noop, 문턱 미달, 억제가 갈린다. |
| 선택의 기술 기록과 동일하지 않다 | 본질·차별 | 계보상 반증 | configuration Receipt는 선택 payload를 기록할 뿐 선택 상태 자체가 아니다. |
| ActionOut과 동일하지 않다 | 본질·차별 | 계보상 반증 | Decision과 외부 명령 출력은 별도 단계다. |
| 선택 이유가 하나의 원인으로 환원된다 | 제외 | 근거 없음 | Ghost, Editor, Will, Map, 자원 제약이 경쟁 설명으로 남는다. |
| 장기 전략 채택과 항상 동일하다 | 제외·보류 | 대비 부족 | 시간 범위·철회 조건·하위 행동 관계가 확인되지 않았다. |
| 반드시 body authorization을 거쳐야 성립한다 | 제외 | 역할상 반증 | 신체 허가는 수행 단계 후보이며 경로 선택의 필수 조건으로 확인되지 않았다. |

## 코퍼스 확인 대비 사례

Chapter 02 §3.2는 같은 표면 행동 `연락하지 않음`을 다음처럼 나눈다.

- 경계를 존중해 안정된 noop을 선택한 경우
- 두려움 때문에 Probe 문턱을 넘지 못한 경우
- 분노를 억제해 Residual이 남은 경우

이 대비는 외부 비행동만으로 선택·문턱 미달·억제를 합칠 수 없음을 보여준다. 저장소 내부 이론 사례이며 인간 일반에 대한 독립 관측 증거는 아니다.

## concept 관계

- 상위 개념 후보: 행동 결정 상태
- `C0002`: `RELATED`; 선택은 occurrence에 선행할 수 있지만 발생을 보장하지 않는다.
- `C0003`: `RELATED`; 선택은 결과 상태가 아니다.
- configuration Receipt: `RELATED / ENGINE-ONLY`; 선택을 기록한 기술 payload다.
- `ActionOut`: `RELATED / ENGINE-ONLY`; 선택된 내용을 외부 실행기로 전달하는 출력이다.
- `StrategyAdoption`: `NARROWER-OR-RELATED-CANDIDATE`; 장기 전략 채택과 단일 행동 경로 선택의 동일성이 확인되지 않아 `HOLD`한다.

## 이 구분이 보존하는 것

선택 후 수행되지 않은 경우와 애초에 선택되지 않은 경우를 구별한다. 또한 선택, 선택 기록, 명령 출력과 실제 수행을 독립적으로 판정할 수 있게 한다.

## 정의 초안

둘 이상의 가능한 행동 경로 가운데 하나가 이후 수행 대상으로 채택된 결정 상태.

## 명칭

- 권장 용어: 미정
- 작업용 서술: 행동 경로 선택
- 역사적 명칭: `Commit`, 일부 Decision 역할

`StrategyAdoption`은 C0001의 synonym으로 승인하지 않는다.

## 경계 조화

- `H0002` — 실행 사슬을 분리한 최초 조화 기록
- `H0003` — StrategyAdoption의 `MERGE → C0001`을 철회하고 관계 후보와 HOLD로 교정

## 남은 불확실성

- 선택과 Intent가 항상 별개인지
- 안정된 noop을 적극적 선택으로 볼 조건
- 선택이 없는 문턱 미달과 선택 후 수행 실패를 가를 근거
- 장기 전략 채택과 단일 행동 경로 선택의 generic·associative 관계
