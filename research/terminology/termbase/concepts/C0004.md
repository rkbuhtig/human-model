# C0004

## 작업 설명

특정 occurrence가 성립했다는 내용을 이후 참조할 수 있도록 보존한 기록을 다룬다. 결과 상태 기록, strategy configuration Receipt, 판정 receipt, 미확정 재료 store, 실행 trace와 인간 지속 상태는 이 concept에 포함하지 않는다.

## 현재 판정

`KEEP`

현재 코퍼스는 occurrence와 그 occurrence에 관한 기록을 분리할 필요를 제공한다. 모든 인간 기억이나 내부 상태가 기록 객체로 존재한다는 뜻은 아니다.

## 연결된 입력 후보

- `X-CH02-007`의 occurrence record 역할
- `X-CH05-033`의 action receipt 요구
- `X-CH06-034` — configuration Receipt는 실제 수행 전에 존재함
- `X-CH06-036` — performed-action record와 outcome observation 분리 요구

`X-CH02-007`의 판정 기록 역할은 이 concept에 자동 포함하지 않는다.

## 특성 분석

| 특성 | 판정 | 근거 권한 | 출처와 판단 |
|---|---|---|---|
| 특정 occurrence가 성립했다는 내용을 표상한다 | 본질 | 계보 | 발생 기록 역할 |
| 이후 참조할 수 있도록 보존된다 | 본질 | 계보 + 현재 사용 | Ledger/JOT의 occurrence record 역할 |
| 기록 대상 occurrence의 성립과 독립적으로 존재·부재하거나 잘못될 수 있다 | 본질·차별 | 코퍼스 확인 사례 | 큰 소리 발생과 올바른 기록이 별도 질문이다. |
| 기록 존재와 기록 정확성이 별도 판정이다 | 본질·차별 | 코퍼스 확인 사례 | 기록이 있어도 틀릴 수 있다. |
| strategy configuration Receipt와 동일하지 않다 | 본질·차별 | 계보상 반증 | configuration Receipt는 수행 전에 발행된다. |
| persistent human state 편입과 동일하지 않다 | 본질·차별 | 계보 | Record/JOT와 State를 분리한다. |
| 결과 상태·outcome observation을 반드시 표상한다 | 제외 | 대상 차이 | 별도 observation/record cluster다. |
| append-only·hash·ID 형식을 가져야 한다 | 엔진 의존 후보 | 구현 | 인간 concept의 필수 특성이 아니다. |
| 기록이 truth나 warrant를 자동 보증한다 | 제외 | 계보상 반증 | record integrity와 claim truth는 별도다. |

“performed-action record를 포함할 수 있다”는 외연 확장절은 정의와 본질 특성에서 제거했다.

## 코퍼스 확인 대비 사례

Chapter 02 §4.1은 큰 소리가 실제로 일어난 것과 그것을 사실로 올바르게 기록한 것을 별도 검사로 둔다. occurrence는 기록 없이도 성립할 수 있고 기록은 존재하면서도 부정확할 수 있다.

Chapter 06의 configuration Receipt는 action occurrence보다 먼저 발행된다. 따라서 `Receipt`라는 철자만으로 C0004가 되지 않는다.

## concept 관계

- 상위 개념 후보: occurrence에 관한 표상
- `C0002`: `RELATED`; occurrence record는 occurrence 자체가 아니다.
- `performed-action record`: `NARROWER-CANDIDATE-OF C0004`; 기록 대상이 performed action으로 제한되는 종개념 후보다. 차별 특성 확인 전까지 `HOLD`한다.
- natural-event record: `NARROWER-CANDIDATE-OF C0004`; 아직 독립 C-ID를 열지 않는다.
- outcome record: `RELATED-OR-SIBLING-CANDIDATE`; C0003 cardinality·observation cluster에서 판정한다.
- strategy configuration Receipt: `RELATED / ENGINE-ONLY`; occurrence 성립을 표상하지 않는다.
- C0009 후보군: `RELATED`; work·spend·dependency·attribution을 표상하는 기술 기록과 대상이 다르다.

## 이 구분이 보존하는 것

기록되지 않은 occurrence도 실제로 성립할 수 있고, 존재하는 기록도 틀리거나 불완전할 수 있음을 보존한다. 또한 설정 기록과 발생 기록을 구별한다.

## 정의 초안

특정 occurrence가 성립했다는 내용을 이후 참조할 수 있도록 보존한 표상.

## 명칭

- 권장 용어: 미정
- 작업용 서술: occurrence record
- 역사적 명칭: `Commit`, `Event`, `Ledger`, `JOT`의 일부 기록 역할

`performed-action record`와 `action receipt`는 C0004의 synonym으로 승인하지 않는다.

## 경계 조화

- `H0002` — performed-action record를 C0004에 병합했던 최초 기록
- `H0003` — 해당 MERGE를 철회하고 generic narrower 후보로 교정

## 후속 분석 대상

- performed-action record의 추가 차별 특성
- 결과 상태 기록과 observation artifact의 경계
- 판정 기록
- 실행 provenance
- 인간 기억 흔적과 외부 기록의 공통 상위 concept 가능성
- 기록의 최소 지속성과 재접근 조건
