# C0004

## 작업 설명

발생 또는 판정에 관한 내용을 이후 참조할 수 있도록 보존한 기록을 다룬다. 기록을 원 사건, 기록 내용의 정확성, 인간의 지속 상태, 적용 권한과 합치지 않는다.

## 현재 판정

`KEEP`

이 판정은 현재 연구에서 발생과 기록을 분리하는 어휘가 필요하다는 뜻이다. 모든 인간 기억이나 내부 상태가 기록 객체로 존재한다는 뜻은 아니다.

## 연결된 입력 후보

- `X-CH02-007` — 발생 또는 판정이 기록으로 남음

다음 후보는 현재 사용과 경계를 확인할 때 사용하지만 자동 통합하지 않는다.

- `X-CURR-016` — record·provenance·receipt가 상태 변화와 별도로 사실과 계보를 보존함
- `X-CH02-013` — 미확정 재료 store
- `X-CH02-015` — persistent state 편입
- `X-CH03-010` — append-only 비권위 로그
- `X-CH03-033` — source 접근 provenance 사건
- `X-CH03-034` — 실행 의존성 trace

## 특성 분석

| 특성 | 판정 | 근거 권한 | 출처와 판단 |
|---|---|---|---|
| 발생이나 판정에 관한 내용을 표상한다 | 본질 | 계보 | `X-CH02-007` |
| 이후 참조할 수 있도록 일정한 형태로 보존된다 | 본질 | 계보 + 현재 사용 | Ledger/JOT record와 현재 receipt·record 사용 |
| 원 사건의 성립과 독립적으로 존재하거나 부재할 수 있다 | 본질·차별 | 코퍼스 확인 인간 장면 | Chapter 02 §4.1은 큰 소리의 발생과 올바른 사실 기록을 별도 질문으로 둔다. `C0002`와 갈린다. |
| 기록 내용의 정확성은 기록 존재와 별도로 판정된다 | 본질·차별 | 코퍼스 확인 인간 장면 | 실제 사건이 있어도 잘못 기록할 수 있고, 기록이 있어도 사실성을 자동 승인하지 않는다. |
| 기록됨이 곧 persistent human state 편입을 뜻하지 않는다 | 본질·차별 | 계보 | `Record/JOT ≠ State`; `X-CH02-015`와 분리한다. |
| append-only 형식이나 hash·ID를 가져야 한다 | 제외 | 엔진 의존 | 구현 기록의 무결성 특성이며 인간 concept의 필수 특성이 아니다. |
| 기록이 곧 epistemic evidence나 truth warrant다 | 제외 | 계보·현재 사용상 반증 | Chapter 03의 `Trace/Facts ≠ claim truth`; RFC의 certification/provenance 분리 |

## 코퍼스 확인 대비 사례

Chapter 02 §4.1은 큰 소리가 실제로 일어난 것과 그것을 사실로 올바르게 기록한 것을 별도 검사로 둔다. 이 대비는 사건이 기록 없이도 성립할 수 있고, 기록의 존재만으로 정확성이 보장되지 않음을 보여준다.

Chapter 02 §3.4의 pending record는 “아직 답이 없음”을 거짓 결론 없이 보존한다. 기록은 미결 상태를 나타낼 수 있으며 확정 결과와 동일하지 않다.

## 상위 개념과 관계

- 상위 개념 후보: 사건·판정에 관한 표상
- `C0001`과의 관계: 선택 기록은 선택 자체가 아니다.
- `C0002`와의 관계: 발생 기록은 발생 자체가 아니다.
- `C0003`과의 관계: 결과 기록은 결과 자체가 아니다.
- `X-CH02-013`과의 관계: 미확정 재료 저장소는 기록의 한 구현일 수 있으나 동일 concept인지 보류한다.
- `X-CURR-016`과의 관계: provenance·receipt 전체는 이 concept보다 넓으므로 현재는 부분 교차만 인정한다.

## 정의 초안

발생 또는 판정에 관한 내용을 이후 참조할 수 있도록 보존한 표상으로, 원 사건의 성립과 기록 내용의 정확성은 별도로 판정되는 것.

## 명칭

- 권장 용어: 미정
- 작업용 서술: 발생 기록
- 역사적 명칭: `Commit`, `Event`, `Ledger`, `JOT`
- 현재 기술 명칭: `record`, `receipt`

현재 기술 명칭은 provenance·판정 기록까지 포함하므로 이 concept와 자동 동일시하지 않는다.

## 남은 불확실성

- 사건 기록과 판정 기록을 한 concept로 유지할지
- 인간 기억 흔적과 외부 기록의 공통 상위 개념
- 기록의 최소 지속성과 재접근 가능성 조건
