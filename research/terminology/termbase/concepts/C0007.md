# C0007

## 작업 설명

실제로 수행된 탐색·비교·재표현·수리 활동을 구분하기 위해 열렸던 concept다. 현재 파일은 이 활동들이 하나의 수행 노동 concept의 종인지, 하나의 과정 안의 부분인지, 서로 연관된 별도 활동인지 충분히 가르지 못했다.

## 현재 판정

`HOLD`

기존 `KEEP`을 철회한다. `탐색·비교·재표현·수리와 같은 처리`는 genus와 differentia가 아니라 예시 목록으로 외연을 암시한다. 관계와 대비 사례가 닫히기 전에는 독립 인간 concept로 승인하지 않는다.

## 연결된 입력 후보

- `X-CH04-004` — 사회적 행동이 후보 생성·비교·수리 노동을 호출하고 분배함
- `X-CH04-023` — 실제 scan·compare work 뒤 coverage 변화가 남음
- `X-CH06-001` — 감당 요구·실제 수리·체감 완화 분리
- `X-CH06-019` — current raw repair와 과거 burden settlement 분리
- `X-CH06-036` — Choice·PerformedAction·Outcome 분리 요구

## cardinality 감사

| 후보 | generic 질문 | partitive 질문 | associative 질문 |
|---|---|---|---|
| 탐색 노동 | 수행 노동의 종인가 | 더 큰 문제 해결 과정의 탐색 단계인가 | 비교·수리를 위한 후보를 제공하는가 |
| 비교 노동 | 수행 노동의 종인가 | 탐색 뒤 선택 과정의 부분인가 | 판단·수리를 지원하는가 |
| 재표현 노동 | 수행 노동의 종인가 | 비교·수리 과정의 수단 또는 단계인가 | 이해·전달을 바꾸는 연관 활동인가 |
| 수리 노동 | 수행 노동의 종인가 | 복구 과정의 실행 부분인가 | repair demand·resource spend와 연관되는가 |

현재 자료는 `요구됨 ≠ 수행됨`, `수행됨 ≠ 성공함`, `수행됨 ≠ 비용`은 보여주지만 위 활동들의 generic/partitive 관계를 결정하지 못한다.

## definition gate

- `~와 같은`: differentia 자리에 예시가 들어감
- 단일 genus + differentia 재작성: 현재 실패
- 판정: HOLD

## 확인된 경계

다음 경계는 계속 유지한다.

```text
work requested / allocated
≠ work performed

strategy configured / Receipt minted
≠ performed activity

activity performed
≠ resource expenditure
≠ successful outcome
≠ record of performance
```

이 경계는 수행 활동군의 필요성을 보여주지만 하나의 C0007 concept를 증명하지 않는다.

## concept 관계 후보

- `C0006`: `RELATED`; 비권위적 인과 영향은 활동 방향을 바꿀 수 있지만 활동 자체가 아니다.
- `C0008`: `RELATED`; 실제 자원 지출은 수행 내용과 다른 축이다.
- `C0009` 후보군: `RELATED`; 활동 기록은 활동 자체가 아니다.
- `C0002`: `RELATED`; 외부 수리 행동은 occurrence이기도 할 수 있지만 활동 내용 분류와 사건 성립 분류는 다르다.
- 탐색·비교·재표현·수리: 각각 `NARROWER / PART / RELATED CANDIDATE`; 현재 HOLD.
- BodyAuthorization: `RELATED-CANDIDATE`; 모든 인지 활동의 필수 part로 승인하지 않는다.

## 이 구분이 보존하려 했던 것

누군가에게 생각·비교·수리를 요구한 것, 전략을 설정한 것, 실제 처리가 수행된 것, 비용이 소비된 것과 결과가 생긴 것을 분리하려 했다. 현재 파일은 이 문제를 보존하지만 하나의 concept 정의에는 도달하지 못했다.

## 정의 초안

`보류`.

탐색·비교·재표현·수리의 generic/partitive 관계가 닫히기 전에는 정의를 발행하지 않는다.

## 명칭

- 권장 용어: 없음
- 작업용 표제: 수행 활동 후보군
- 역사적 명칭: interaction work, scan work, compare work, `Work_cov`, Repair

이 명칭들은 synonym 집합으로 승인되지 않았다.

- `H0003` — C0007 KEEP을 철회하고 generic/partitive 감사로 전환

## 재개 조건

- 인지 노동·사회적 수리·신체 수행의 공통 genus 여부
- 자동 처리와 노력 노동을 가르는 차별 특성
