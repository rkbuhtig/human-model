# H0002 — 전략 설정·행동 수행·결과 사슬 조화

## 상태

`SUPERSEDED IN PART BY H0003`

이 기록은 Chapter 05·06의 실행 사슬을 처음으로 동시에 비교한 조화 기록이다. 다음 경계를 분리한 관찰은 유지한다.

```text
선택됨
≠ configuration Receipt가 발행됨
≠ ActionOut이 출력됨
≠ 몸이 허가함
≠ 실제 행동이 수행됨
≠ 세계 결과가 생김
≠ 결과가 관측됨
≠ 각 단계가 기록됨
```

그러나 이 기록은 generic relation을 synonymy로 잘못 읽어 네 후보를 `MERGE`로 판정했다. 해당 동일성 판정은 `H0003`에서 철회했다.

## 유지되는 판정

### ActionOut / Gate_Action

`ENGINE-ONLY`

외부 실행기로 전달되는 명령·출력과 구현 gate다. actual occurrence와 world outcome을 보증하지 않는다.

### configuration Receipt 계열

`ENGINE-ONLY`

- `Receipt`
- `PledgeFn`
- `AttachMeta`
- `Receipt-only`
- `PayloadFirewall`
- `pledge_t`, `pledge_{t-1}`, `pledge_next`

strategy knob configuration과 저장·접근 계약을 나타내며 실제 수행·지출·결과·의무 성립을 보증하지 않는다.

### pledge 명칭

`HISTORICAL-ONLY`

초기의 미래 자기서약과 후기의 controller strategy payload를 한 철자로 가리킨 역할 이동만 보존한다.

### BodyAuthorization / outcome observation

`HOLD`

긍정 정의와 형제 대비가 부족하다.

## 철회된 판정

다음 `MERGE`는 synonymy가 아니라 상·하위 또는 연관 가능성을 나타낸 것이므로 철회한다.

| H0002 최초 판정 | 교정 상태 |
|---|---|
| StrategyAdoption `MERGE → C0001` | `HOLD`; C0001의 NARROWER/RELATED 후보 |
| PerformedAction `MERGE → C0002` | `HOLD`; C0002의 NARROWER 후보 |
| ExternalOutcome `MERGE → C0003` | `HOLD`; C0003의 RELATED/NARROWER 후보 |
| performed-action record `MERGE → C0004` | `HOLD`; C0004의 NARROWER 후보 |

철회 이유:

- 동일한 genus·differentia·외연이 확인되지 않았다.
- “포함한다”는 외연 관계를 동일성으로 읽었다.
- C0003은 자체 cardinality가 닫히지 않았다.
- 차별 사례 부족을 synonymy 근거로 잘못 사용했다.

## C0007·C0009 교정

- C0007: 탐색·비교·재표현·수리의 generic/partitive 관계가 미정이므로 `KEEP → HOLD`.
- C0009: work record·spend record·dependency trace·attribution record를 한 subject field로 묶었으므로 `ENGINE-ONLY → HOLD / SUBJECT-FIELD SPLIT`.
