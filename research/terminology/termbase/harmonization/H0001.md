# H0001 — C0006의 시간 범위 교정

## 대상 concept

- `C0006` — 기존 작업용 서술: 비권위적 미래 편성 영향

## 교정 유형

`BOUNDARY REFINEMENT / KEEP`

새 concept를 만들거나 둘을 병합하는 조화가 아니다. 기존 C0006의 본질 특성과 역사적 구현 특성을 다시 나눈다.

## 교정 계기

Chapter 03·04에서 C0006을 처음 분석할 때 확인된 영향 경로는 주로 다음 tick의 탐색·비교·후보 편성으로 표현됐다.

```text
current readout
→ next-tick search / comparison / candidate influence
```

Chapter 05·06은 이 안전장치가 무엇을 막으려 했는지 더 정확히 드러냈다.

- `X-CH05-018~021` — active/next policy·candidate manifest와 CandidateGen 경로
- `X-CH05-023` — STG branch의 same-tick Propose→Select 재개방
- `X-CH06-029~033` — View backflow, bounded CtrlCtx, hidden Grounds handle, Grounds/Influence 분리
- `X-CH06-037~038` — Grounds·Control Influence·Accounting Imprint scope 충돌과 same-commit 금지의 정확한 범위

## 기존 경계의 문제

기존 명칭과 정의는 `미래`, `next-tick`, `지연`을 concept의 본질처럼 강하게 포함했다.

그러나 Chapter 06의 교정은 금지 대상이 모든 즉시 영향이 아니라 다음 역류임을 보여준다.

```text
현재 surface·policy output
→ 같은 irreversible commit의 Grounds·decision·writer 권한
```

주의 전환, 보호 반응, 가역적 전략 변경, 후보 재배치 같은 즉시 영향은 외부 사실의 Grounds나 비가역 write authority를 얻지 않는 한 C0006의 범위에서 배제할 이유가 없다.

## 교정된 경계

C0006의 본질은 다음이다.

```text
현재의 체험·서사·압력·우선 방향이
사실 근거·warrant·비가역 writer 권한을 자동 획득하지 않으면서
가역적 주의·탐색·후보·전략·행동 편성에 인과적으로 기여함
```

다음은 본질이 아니다.

- 반드시 한 tick 이상 지연됨
- 반드시 `Policy_{t+1}`를 경유함
- 반드시 `k`, `ρ`, `GateBias`, `CtrlCtx` 같은 구현 노브를 사용함
- Grounds digest를 작은 handle로 포장하면 합법 Influence가 됨

## 판정

- C0006의 `KEEP` 판정은 유지한다.
- 작업용 서술을 `비권위적 인과 영향`으로 교정한다.
- `next-tick influence`, delayed causal lane은 역사적 명칭과 구현 계보로 유지한다.
- same-tick 영향은 자동 허용하지 않는다. 같은 irreversible commit의 Grounds·decision·writer 역류 여부를 별도로 검사한다.
- C0006을 Grounds, Warrant, selection authority, accounting imprint와 병합하지 않는다.

## 이 교정이 보존하는 것

다음 두 오류를 동시에 피한다.

```text
주관적 값은 즉시 영향을 줄 수 있으므로 곧 사실·권한이다
×

사실·권한이 아니므로 어떤 즉시 인과 역할도 가질 수 없다
×
```

체험·서사가 실제 행동과 탐색을 바꿀 수 있다는 점을 보존하면서, 그것이 자신이 촉발한 외부 판정과 비가역 기록을 스스로 인증하지 못하게 한다.
